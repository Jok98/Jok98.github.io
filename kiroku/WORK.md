# Lavoro

## In corso

- Nessuna attività di implementazione globale o cross-track è confermata.

## Da fare

- Nessun backlog del repository è dichiarato da codice o documentazione.
- Le caselle non selezionate nelle roadmap sotto `notes/` descrivono argomenti di studio e non devono essere promosse automaticamente a task tecnici.

## Bloccato

- Nessuna attività registrata come bloccata.

## Regola di instradamento

- Per una futura modifica non banale, creare una track solo se esiste un obiettivo distinto con milestone, criteri di completamento o necessita di handoff.
- Le opportunita tecniche rilevate dall'analisi restano rischi o idee finché l'utente non le autorizza come lavoro.
